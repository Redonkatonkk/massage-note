# UI 设计记录

## 设计方向

工作台沿用原有暖米色与砖红配色：砖红表达品牌与主要操作，白色卡片承载内容，暖米色区分次级表面，橙色提示待处理状态，绿色保留为成功与在岗状态。整体保留清晰层级和较高的信息密度，方便门店在营业期间快速查找与录入。

## 布局与导航

- 财务移除独立现金结算标签并合入日结员工检查表，共用营业日选择器。表格新增应提交、应保留、现金结清状态与操作列，其他现金金额及操作信息通过原生 details 按行展开；表格上方保留一键全部结清。现金状态不改变日结按钮可用性，现金加载失败显示重试并暂禁现金操作。员工在我的日结仅查看本人现金明细。中英文共用布局，窄屏横向滚动，展开入口支持键盘。


- 屏幕宽度达到 1200px 时，侧栏默认收起为 56px 图标栏，距窗口左侧 4px，图标点击区域至少 44px 宽；鼠标移入或键盘聚焦时，以 240ms 动画展开为 224px，离开后自动收起（键盘仍在操作时保持展开）；点击含子菜单的项目仅固定对应分组，不固定侧栏宽度，重复点击或按 Escape 解除固定。主内容从侧栏右侧 12px 处开始，右侧留 18px，并取消桌面内容宽度上限以充分利用窗口宽度。展开侧栏浮于内容上方，避免表格宽度跳动。
- 小屏继续使用同一组导航入口，显示为底部浮动导航栏，并适配设备安全区。
- 记工与财务页的 AI 助手作为导航栏固定入口，使用星光图标；桌面侧栏收缩时只显示图标，展开时显示“AI 助手”文字，小屏作为底栏第五项显示。点击打开对应的记工/财务对话面板，面板通过 body portal 展示，避免被导航的滚动、裁切与定位影响；桌面面板位于侧栏右侧，小屏保留视觉视口与软键盘适配。关闭按钮或 Escape 关闭后焦点回到入口。
- 记工页仅在浏览器宽度达到 1200px 时使用分区页头，移除日期/按钮的大卡片容器：常驻日历在主内容最左侧，刷新、日结等操作紧邻日历右侧并靠底部排列，店铺信息区保留在整个主内容右侧，记工标题、日期与同步状态、下方账号按钮均以第一行店铺信息的左边缘为基准左对齐。日历宽 340px、日期行高 28px、月份导航高 28px、网格间距 2px，去掉日历底板和边框；已日结金额继续显示在日期下方。所有含导航栏的宽屏页面将中英文切换放在侧栏底部、使用帮助上方，收起时纵向排列，展开时横向排列，同时隐藏全局顶部入口。低于 1200px 保留全局语言入口、原来的标题下方营业日工具栏与点击展开日历，760px 及以下沿用原工具栏换行；缩放窗口即时切换，保留所选营业日、权限与营业额标记。无导航栏的登录或初始化页面保留顶部语言入口。财务页始终点击展开日期选择器。
- 记工页宽屏取消“更多操作”外层菜单，短信队列及已日结后的发送小结、取消日结按原权限直接显示；队列按钮以小数字徽标表示已发送数量，隐藏日历底部说明。窄屏恢复“更多操作”及 10 秒自动收起、“已发送 N”文字与“有记工但未日结”日历图例；财务页也保留图例。两个模式共用业务回调，队列弹窗继续通过 body portal 展示。
- 宽屏记工页删除独立的营业日日期与状态说明区域，所选日期仍在标题下方和日历中显示；“返回今天”位于“取消日结”右侧，仅查看非今天时显示。窄屏保留日期选择器及说明，“返回今天”随次要操作放入“更多操作”，员工查看非今天时也可使用。中英文共用此布局。
- 导航入口覆盖记工、财务、店铺设置和个人页面；当前页面和分区以背景突出。鼠标移入财务或店铺设置时自动展开对应子菜单，移到另一项主导航时切换展开分组；鼠标可直接移入子项选择，未固定时离开侧栏后收起（键盘仍在操作时保持展开）。点击财务或店铺设置名称只固定展开子菜单，通过子项进入页面；固定时悬停其他主项不会切换分组；鼠标移出整个侧栏后仍自动缩回图标栏，再次移入时显示之前固定的子菜单，点击另一分组可切换固定项。子菜单以 220ms 动画展开/收起；主导航不显示右侧箭头，四个选项占满相同宽度，键盘聚焦主导航或子项时也会展开对应分组。
- 子菜单与页面标签共用角色配置，员工仍只显示现有可用分区。同页切换同步页面状态和 URL，跨页使用带店铺与分区的链接；刷新可回到当前分区。小屏继续用页面标签切换分区。
- 登录页展示“记工 → 收款 → 日结”的工作流程，并在窄屏下调整为单列。

## 组件与状态

- 快速记工弹窗通过 body portal 定位；标题、高亮与关闭按钮固定在顶部，仅下方表单独立滚动。桌面限制在视口留白内，小屏底部对齐并保留安全区，长项目列表、自定义输入及中英文切换均不让关闭入口随表单滚出。

- 按钮统一圆角、字重、禁用状态和短促的 hover/按压反馈；表单沿用统一边框、焦点环和品牌强调色。
- 卡片以暖白表面、细边框和轻阴影分组；指标卡用数字等宽特性提升金额扫读效率。
- 记工面板突出“营业额（折扣后）”和“总收入”，并保留指标说明，帮助区分口径。
- “待结账”使用浅橙背景与橙色边线；人工标记的记工卡片持续显示黄色背景与金色边框，包括未悬停、待结账和已日结只读状态，状态样式优先于普通卡片底色。高亮卡片在鼠标移入、移出和按下时保持同一底色、边框与阴影，不应用变色、浮起、缩放或过渡。
- 操作成功、失败、保存、发送和表单校验等临时提示统一在 3 秒后消失；重复触发同一条提示重新计时，切换页面或关闭组件清理计时。记工弹窗错误提示使用同一计时规则，不依赖 CSS 动画结束。加载失败的错误文字自动消失，但重试入口和业务操作限制保留；同步、离线、已日结等持续状态仍随实际状态显示。
- 同步状态沿用浅绿底色与绿色文字，离线沿用浅红底色与红色文字；成功提示与已日结提示采用浅绿底色和绿色文字。
- 动效仅用于按钮反馈、卡片状态、弹层、日期选择器和导航展开等短交互；不让装饰动画干扰高频工作。
- 保留清晰的键盘焦点样式，并响应系统减少动态效果偏好。
- 现有中文与英文界面继续沿用同一套布局、组件状态和导航结构。
- 工资页选择区宽屏采用左右两列（总宽最多 536px、间距 16px），左列最多 160px 宽，上方为纵向员工按钮列表（超过 360px 高时独立滚动），下方为工资来源和生成按钮，控件单列铺满并允许英文按钮文字折行；右列仅显示紧凑月历。767px 及以下改为上下排列，员工按钮上方横向滚动；月历宽度最多 360px，窄屏不超过容器宽度，日期格最小高度 44px，标题与图例采用紧凑间距；月历一周七列，端点用品牌实色、范围用浅色，黄色/绿色对号分别标记现金与非现金，文字说明及日期可访问名称补充颜色含义。生成结算单后，1024px 及以上采用员工操作列 160px、日历列 360px、汇总列三列布局（取消总宽度上限，汇总填满日历右侧剩余空间）；三列按最高内容统一高度，日历日期行均分剩余高度且最小 44px，生成与结算操作分别靠底；超过 6 名可查看成员时左栏拓宽至 224px，员工按钮按两列排列（十人五行，更多成员保留 360px 高列表内滚动）。汇总列保留员工、范围、完整收入矩阵与总额、未结/抵扣/实付和付款/生成图片/短信/发送记录操作，抵扣说明可展开，逐日明细独立放在下方。1023px 及以下员工保持单列、汇总位于选择区下方，389px 及以下付款字段及单一来源汇总改为单列；汇总内容宽度达到 480px 时按自身宽度增大字号、金额与间距，避免宽屏仍使用挤压的小字；金额始终保留美分。

## 实现入口

下列路径均相对于本文件所在的 `docs/engineering/` 目录：

- [`globals.css`](../../apps/web/app/globals.css)：颜色、表面、状态、阴影和动效时间等 CSS token，以及基础样式。
- [`design-system.css`](../../apps/web/app/design-system.css)：非响应式的按钮、表单、卡片、指标、登录与导航视觉样式。
- [`responsive.css`](../../apps/web/app/responsive.css)：响应式断点；1200px 起切换为桌面侧栏，小屏保留浮动底栏。
- [`primitives.tsx`](../../apps/web/app/ui/primitives.tsx)：品牌标记、图标和指标组件。
- [`app-nav.tsx`](../../apps/web/app/app-nav.tsx)：导航项目、子菜单展开、当前页面与分区状态。
- [`app-navigation.ts`](../../apps/web/lib/app-navigation.ts)：财务/设置的角色菜单、分区校验和深链接。
- [`use-navigation-tab.ts`](../../apps/web/app/use-navigation-tab.ts)：页面分区与 URL 同步。
- [`today-board.tsx`](../../apps/web/app/today-board.tsx)：营业额、店铺收入、总收入指标及待结账记工卡片。
- [`massage-note-app.tsx`](../../apps/web/app/massage-note-app.tsx)：页头店铺、营业日与账号控件，以及常驻日历的日期与刷新状态。
- [`business-date-picker.tsx`](../../apps/web/app/business-date-picker.tsx)：记工页按宽度切换常驻/弹出两种日期模式，财务页始终弹出。
- [`use-auto-dismiss-state.ts`](../../apps/web/app/use-auto-dismiss-state.ts)：跨页面共用的临时反馈状态；[`feedback-timer.ts`](../../apps/web/lib/feedback-timer.ts) 统一 3 秒计时、重新触发和清理。
- [`language-provider.tsx`](../../apps/web/app/language-provider.tsx)：共享语言状态与语言切换组件，供全局工具栏和桌面侧栏复用。
- [`login/page.tsx`](../../apps/web/app/login/page.tsx)：登录介绍和工作流程展示。

业务金额的名称、权限可见范围、计算语义和历史快照仍由现有业务实现决定；视觉调整不得改写这些约定。待结账橙色高亮与金色人工标记各自表达不同状态，应继续区分。
