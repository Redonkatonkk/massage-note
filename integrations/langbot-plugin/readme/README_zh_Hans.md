# Massage Note 记工助手

插件 **1.2.0**，要求 Massage Note API **至少 1.3.7**，协议版本 2。每次 AI 请求附带同一机器人、群和发送者最近 5 轮对话（用户原文和实际机器人回复）；空闲 30 分钟后过期，插件重启清空。

在微信群 @ 专用机器人后，插件读取店铺实时目录和自然语言说明，由模型理解消息，再提交受限记工意图。最终金额、员工、权限、日结限制和幂等写入均由后端校验。

## 配置

| 字段 | 含义 |
| --- | --- |
| `api_base_url` | API 最终 HTTPS 地址及前缀；本地例外仅 `host.docker.internal` |
| `integration_token` | 后端配置的独立集成令牌，在插件配置中填写 |
| `bot` | 专用于记工的机器人 |
| `model` | 理解实时目录、店铺说明及用户消息的模型 |

配置令牌不要放进安装包；隔离插件进程不会继承容器的自定义环境变量。流水线只允许被 @ 的群消息触发。携带令牌的 API 请求不跟随重定向。

## 使用概览

- `绑定店铺 123456`、`绑定 Lily`：绑定群与微信身份。
- `Lily 大力 60`：按店铺配置上工；说明可设置项目别名与默认时长。
- `Jessica 75 5`：仅在店铺已约定该下工格式与付款方式时，按实际数字收款；明确现金或刷卡优先。
- `Lily 加热石`、`Lily 取消高亮`：修改唯一待付款记录；多个匹配时需指定编号。
- `查询 Lily 最近 15 天折后大费，第 2 页`：范围查询与分页，总计覆盖完整范围。
- `删除 <完整记录编号>`、`恢复 <完整记录编号>`：按现有权限软删除与恢复。

还支持加项、折扣、混合付款、自定义项目、历史补录与按编号编辑。实收不覆盖项目原价；日期、金额或对象不明确时不猜测。模型解析失败最多复核一次，持续不合格会明确报错。

## 数据访问与安装

店主或经理须在 Massage Note 的“店铺管理 → 记工机器人 → 微信群绑定”核实微信身份，才能开启相应历史访问。员工只能查询本人历史，已核实的经理和店主可查询全店；查询回复会发送到发起请求的群。

先部署符合要求的 API 并执行迁移，再通过 LangBot“插件 → 本地安装”选择新构建的 `.lbpkg`。安装后核对 `mounted` 和 `initialized` 日志。不要直接复制到运行数据目录来代替安装。

仓库中的 `docs/operations/LANGBOT_WORK_BOT.md` 是完整业务与运维手册；源码目录的 `DEVELOPMENT.md` 说明目录、测试和打包方式。本文随插件包分发，仅保留配置与使用概要。

历史仅存插件进程内存，并按当前店铺上下文和插件配置隔离，最多保留 256 个会话；用户原文或回复超过 4,000 字符的整轮不纳入记忆。历史不能替代当前指令的原文证据、数据库实时查询或后端权限校验。

## 学习记忆（插件 1.4.0 / API 1.7.0）

歧义和纠正触发 CLARIFY：先说出具体猜测并询问。用户在30分钟内回复“对/是的/确认”等后保存经验；确认只学习，不记账，操作需发送完整指令。纠正会停用同说法旧经验并等待重新确认。最新目录、原文证据、店铺配置和权限校验仍优先，经验不能授权默认时长或付款方式。

记忆使用 LangBot SDK 的 get_plugin_storage/set_plugin_storage 持久保存，按 API 配置、storeId、机器人、群、发送者及绑定姓名隔离；跨日期、重启保留。每个范围保留最近50条经验、30条未理解事件和30条澄清回复（用于去重）。改配置或绑定会切换记忆范围。存储失败会提示，不能宣称已记住。备份包含消息片段，应按运行数据保护。

CLARIFY 只由插件处理，不提交记工 API。需要升级 NAS API 并安装1.4.0插件，旧 API 不启用持久学习。

## 多人员指令（API 1.7.0 / 插件 1.4.0）

`Ling Jessie 上工 大力` 表示为 Ling 和 Jessie 分别上工，共用明确项目与店铺默认时长。插件识别完整员工姓名，不将多人拼成一个姓名；每人可有不同的明确项目和时长。多人下工的共同金额必须明确为每人金额，合计或分配不清先澄清。

解析结果使用 `{ "kind": "BATCH", "actions": [...] }`，含2–10个 START、FINISH 或 ADJUST，每项必须有 memberName/memberMention，员工不得重复，不能嵌套或带 recordId。原文逐项校验，权限及目录逐项复核；同事务全部成功才返回 BATCH_COMPLETED，任一失败回滚全部写入。消息级幂等保存合并回复，重发原消息不会再次执行。需要升级 API 并构建、安装插件包。
